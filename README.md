# Разметка фото и видео в CVAT

## Что сделано

Размечены данные в CVAT для задач компьютерного зрения.
Фотографии и видео. После разметки данные выгружены
в стандартные форматы и проверены на корректность.

## Фотографии: детекция объектов

Размечены объекты на фото с помощью bounding boxes.
Классы: dog, cat, car.

После разметки данные выгружены в формате COCO JSON.

Результат:
- Изображений: 2
- Всего рамок: 3
- Собака: 1, кошка: 1, машина: 1

При открытии файла видно три блока:
images (список фото), annotations (рамки с координатами),
categories (классы). Проверено, что у каждого фото есть рамка,
а координаты не выходят за границы изображения.

Скриншоты:
- screenshots/photo_bbox_dog_cat.jpg — рамки на собаке и кошке
- screenshots/photo_bbox_car.jpg — рамка на машине

## Что проверено

После выгрузки данные проверены по нескольким пунктам.

Фото (bounding boxes):
- У каждого фото есть рамка
- Координаты не выходят за границы картинки
- Классы совпадают с заданными

Полигон:
- Координаты точек полигона не выходят за границы изображения

Видео (трекинг):
- Треков ровно два — собака и кошка. Лишних нет, дублей нет.
- У каждого трека есть ключевые кадры — значит, интерполяция
  использовалась, а не ручная разметка каждого кадра.
- Моменты, когда животные уходили из кадра, отмечены.
- Пропусков нет: все кадры, где объект виден, размечены.
- Координаты рамок не выходят за границы видео.

Ключевые точки:
- Точки сохранены в файле, координаты корректны.

OCR:
- Текст сохранён в атрибуте content, рамка не выходит за границы.

## Что видно в форматах

COCO JSON (для фото и OCR) состоит из трёх частей:
- images — список изображений с размерами
- annotations — рамки с координатами [x, y, width, height]
- categories — список классов

CVAT for video 1.1 (XML) для видео:
- meta — информация о видео и классах
- track — трек объекта с уникальным id
- box — положение объекта на кадре с пометками keyframe, outside

CVAT for images 1.1 (XML) для ключевых точек и полигонов:
- image — изображение с размерами
- points — координаты точек
- polygon — координаты полигона
- label — класс объекта

## Скрипт для проверки разметки

Для проверки выгруженных данных создан Python-скрипт
`check_annotations.py`.

Что проверяет:
- структуру файла (COCO JSON или CVAT XML)
- выход координат за границы изображения
- замкнутость полигонов
- самопересечения полигонов
- нулевую или отрицательную площадь
- наличие аннотаций у каждого изображения
- совпадение классов с ожидаемыми
- дубли аннотаций

Поддерживаемые форматы:
- COCO JSON (bbox, polygon через segmentation)
- CVAT for images 1.1 (XML): box, polygon, points

Примеры запуска:
python check_annotations.py --input annotations/photo_bbox.json
python check_annotations.py --input annotations/car_polygon.xml
python check_annotations.py --input annotations/photo_bbox.json --classes dog cat car
python check_annotations.py --input annotations/car_polygon.xml --strict
